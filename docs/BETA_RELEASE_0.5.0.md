# RBP 0.5.0-beta.1 — release preparation and in-game addon manager

Status: **beta candidate / private recipe validated by tester, NOT publicly released**.

## What is verified

- Current development branch: `dev/ultimate-ui`. Keep `main` unchanged until a separate reviewed merge.
- User validated the Windows beta recipe in the Reborn client on 2026-11-19.
- CI includes native-free source checks and a private preview with Lua 5.1 test suites. The preview must be rechecked on the final commit.
- In-game features: build library, import/export, editor, jewellery, phase notes and read-only live HUD. No auto-picking, card clicks, or banishment by the addon.

## Important distribution gates (not waived by a successful build)

1. **Rights:** `GeneratedCatalog.lua` is derived from the official `data/v1` catalogue and is intentionally excluded from Git history; no redistribution grant has been established. The package generated by CI includes it **for private testing only**. Do not attach this ZIP to a public release or submit it to a public launcher index absent appropriate permission or a different authorized data strategy.
2. **Local mechanics:** Windows recipes may include `GeneratedJewelryMechanics.lua` derived from the player's installed client. Do not distribute this extract without permission. The index candidate must be built from appropriately licensed content and clear provenance.
3. **Repository visibility:** `Maidenquinn/reborn-build-planner` is private. The external launcher needs to download a *public* GitHub release asset. Decide code publishing and license/NOTICE scope before registering.
4. **Game version:** Record a precise client version and run `/rbp diag`, import/export, /reload persistence and HUD checks on the release ZIP. User acceptance is not a license grant.
5. **No published release yet:** The connected GitHub tooling here does not expose a release-creation action. Keep the candidate as a branch build until the above gates are resolved.

## Syiana/azs-addons integration contract

Source: https://github.com/Syiana/azs-addons (README.md and tools/pin.py).

- The external index is a **metadata registry**, not a place to upload the addon. Candidate TOML is in `docs/azs-addons/reborn-build-planner.toml`.
- The actual release ZIP must contain exactly `RebornBuildPlanner/` at the root and `RebornBuildPlanner/RebornBuildPlanner.toc`. Its `## Interface: 30300` is supported. No lab/test addon, readme folder or parent wrapper should enter that ZIP.
- Use one immutable, single, publicly accessible GitHub release asset such as `RebornBuildPlanner-v0.5.0.zip` once licensed and ready. `source.asset = "RebornBuildPlanner-*.zip"` must uniquely match.
- The game will not offer it merely because a release exists. A PR to Syiana/azs-addons must add the TOML, the `index.json` pin is generated/updated by its workflow and reviewed, and the game's maintainers must sign/publish the merged index.
- **Drafts and pre-releases are deliberately excluded** by Syiana's `newest_release`. A `v0.5.0-beta.1` GitHub pre-release can be used for direct testing, **not automatic in-game manager distribution**.
- Never modify `index.json` manually in a way that claims a version/size/SHA-256 for an unpublished or private artifact. Do not submit the candidate TOML until the author and index maintainers agree on distribution readiness.
- In the game's addon list, describe the dependency on built-in `AzerothSurvivors` and `AzerothSurvivorsAPI` (TOC dependencies), not a third-party index dependency.

```powershell
git switch dev/ultimate-ui
git pull --ff-only origin dev/ultimate-ui
powershell -ExecutionPolicy Bypass -File .\tools\build_local_equipment_recipe.ps1 `
  -GameRoot "H:\Users\kevin\Desktop\AzerothSurvivorsReborn\Azeroth Survivors" `
  -GameExe "H:\Users\kevin\Desktop\AzerothSurvivorsReborn\Azeroth Survivors\AzerothSurvivorsGame.exe" `
  -UseCachedCatalog `
  -OutputDir ".\dist\ultimate-0.5.0-beta1-local"
```
